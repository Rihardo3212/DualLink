One-time setup - leave it like this afterwards:

  1. In Free Download Manager open the menu ☰ › Settings › Network
  2. Choose manual proxy configuration with type SOCKS5
  3. Address 127.0.0.1   Port 1080
  4. Optional: allow 8 or more connections per download, so one file can use both links

While DualLink is off, FDM downloads go out over your normal connection. Keep DualLink running in the tray - if it's closed, FDM can't download.

Let DualLink set up qBittorrent for you

DualLink is running, but it can't reach qBittorrent yet. One-time setup:

  1. In qBittorrent open Tools › Options › Web UI
  2. Tick Web User Interface (Remote control) - keep port 8080
  3. Tick Bypass authentication for clients on localhost, click OK

  1. Tools › Options › Connection: Peer connection protocol TCP
  2. Proxy SOCKS5, host 127.0.0.1, port 1080
  3. Tick Use proxy for BitTorrent purposes and Use proxy for peer connections
  4. Click Apply, then pause and resume your torrents
